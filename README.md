## 📌 Overview

WeatherDashboard Pro is a front-end web application that allows users to search for any city and instantly retrieve current weather information. The application integrates with the OpenWeather API to display accurate and real-time weather data through a clean and responsive interface.

This project demonstrates practical knowledge of API integration, asynchronous JavaScript, DOM manipulation, and responsive web development.

---

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature display
* 💧 Humidity information
* 💨 Wind speed details
* ☁️ Weather description with icons
* 📱 Mobile-friendly responsive design
* ⚡ Fast weather updates using Fetch API
* ❌ Error handling for invalid city names

## 🔑 API Configuration

1. Create an account on OpenWeather.
2. Generate an API key.
3. Replace the API key inside `script.js`.

```javascript
const API_KEY = "YOUR_API_KEY";
```

---

## 🚀 How It Works

1. User enters a city name.
2. JavaScript sends a request to the OpenWeather API.
3. API returns weather data in JSON format.
4. The application extracts:

   * Temperature
   * Humidity
   * Wind Speed
   * Weather Condition
   * Weather Icon
5. The information is displayed dynamically on the webpage.
